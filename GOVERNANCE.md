# Governance (initial proposal)

- The public specification, issue tracker, and proposed changes are open to community review.
- The repository maintainer acts as initial editor for the v0.1 draft.
- Wire-level changes should be accompanied by rationale, compatibility analysis, schema updates, and conformance tests.
- No implementation is privileged by the specification; independent implementations should be able to conform using the written documents alone.
- Before v1.0, the project should publish a clearer maintainer succession and decision-making process.
- Release tags should identify the specification version and reference SDK version separately.
